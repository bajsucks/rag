# rag
Easy ragdoll module that works on all rig types

add `bajsucks/rag@^0.1.0` to your wally.toml to install

## Usage
`Rag.Ragdoll(Char)` - ragdoll
`Rag.Unragdoll(Char)` - unragdoll
`Rag.IsRagdolled(Char)` - get current state
all are safe to call whenever but please try not to call them every frame
